Прошивка Macropad

ESP32-P4 · 7″ · 1024×600

  1. Відкрий сторінку у Chrome або Edge на комп’ютері.
  2. Під’єднай USB-C UART кабелем передачі даних.
  3. Зупини USB companion та монітор порту.
  4. Вибери адаптер і дочекайся завершення.

Оновлення зберігає Wi-Fi й прив’язку. Стирання даних потребує повторного налаштування.

Потрібен браузер з Web Serial, наприклад Chrome або Edge.
