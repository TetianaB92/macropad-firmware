Mozilla root certificate bundle for verified HTTPS/WSS downloads from Cloudflare.
Generated using Arduino ESP32 `tools/gen_crt_bundle.py` from
https://curl.se/ca/cacert.pem on 2026-09-07 (121 certificates).

Refresh when roots change, rebuild and flash. Never replace certificate validation
with setInsecure(). Public trust anchors contain no account credentials.
